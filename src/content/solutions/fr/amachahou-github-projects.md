titre: Jira ou GitHub Projects ? → tout au même endroit que le code
pistes: [production]

probleme: Il fallait choisir l'outil de suivi des tâches pour 16 personnes, après une année sur Jira avec Drealm.
compte:
  - Gratuit pour 16 personnes
  - Au même endroit que le code
  - Simple pour les artistes
options:
  - texte: Jira
    raison: payant au-delà d'un certain nombre de personnes
  - texte: GitHub Projects
    retenue: true
etapes:
  - Les tâches sont des issues GitHub, suivies dans GitHub Projects.
  - Les branches et les pull requests sont reliées aux tâches.
  - Les artistes n'ont qu'un seul outil à apprendre.
resultat: Un seul outil pour les tâches et le code, sans abonnement.
